    <h1>🚀 WannnV Portfolio Website</h1>
    <p>Selamat datang di repositori resmi <strong>WannnV</strong>. Website ini adalah landing page portofolio yang dirancang dengan estetika <strong>Premium Dark Mode</strong>, fokus pada kecepatan, dan desain yang bersih untuk memamerkan layanan pengembangan bot Telegram.</p>

    <h2>✨ Fitur Utama</h2>
    <ul>
        <li><strong>Modern UI/UX</strong>: Desain minimalis menggunakan font <em>Space Grotesk</em> dan ikon dari <em>Font Awesome</em>.</li>
        <li><strong>Dual Theme Support</strong>: Transisi halus antara mode gelap (dark) dan terang (light) melalui fitur <em>Theme Switcher</em>.</li>
        <li><strong>Responsive & Lightweight</strong>: Kode yang efisien tanpa library berat, memastikan tampilan mobile-first yang optimal.</li>
        <li><strong>Interactive Elements</strong>: Dilengkapi dengan animasi <em>fade-in</em>, efek <em>glassmorphism</em>, dan transisi hover pada kartu proyek.</li>
    </ul>

    <h2>🛠️ Tech Stack</h2>
    <ul>
        <li><strong>HTML5</strong>: Struktur web yang semantik dan rapi.</li>
        <li><strong>CSS3</strong>: Menggunakan variabel kustom (CSS Variables) untuk manajemen tema dan styling modern.</li>
        <li><strong>JavaScript</strong>: Logika <em>vanilla</em> JS yang sederhana untuk fungsionalitas pengalihan tema.</li>
        <li><strong>Ecosystem</strong>: Dioptimalkan untuk integrasi Python (Pyrogram), Bash (Linux), dan MongoDB dalam pengembangan bot.</li>
    </ul>

    <h2>👤 Tentang Developer</h2>
    <p>Saya adalah seorang <strong>Telegram Bot Developer</strong> yang berfokus pada solusi otomatisasi dan monetisasi digital. Selain mengembangkan bot berkualitas, saya juga menyediakan jasa penyediaan akun Telegram, layanan VPS, serta integrasi Rest API & AI.</p>

    <h2>📂 Struktur File</h2>
    <ul>
        <li><code>index.html</code>: Berisi struktur utama, profil, store menu, dan daftar proyek aktif.</li>
        <li><code>style.css</code>: Berisi seluruh konfigurasi visual, sistem grid, animasi, dan variabel warna.</li>
    </ul>
