# 🚀 WannnV Portfolio Website

Selamat datang di repositori resmi **WannnV**. Website ini adalah landing page portofolio yang dirancang dengan estetika **Premium Dark Mode**, fokus pada kecepatan, dan desain yang bersih untuk memamerkan layanan pengembangan bot Telegram.

## ✨ Fitur Utama
* **Modern UI/UX**: Desain minimalis menggunakan font *Space Grotesk* dan ikon dari *Font Awesome*.
* **Dual Theme Support**: Transisi halus antara mode gelap dan terang hanya dengan satu klik.
* **Responsive & Lightweight**: Kode yang efisien tanpa library berat, memastikan akses cepat di perangkat mobile.
* **Interactive Elements**: Dilengkapi dengan animasi *fade-in* dan efek hover pada kartu proyek.

## 🛠️ Tech Stack
* **HTML5**: Struktur web yang semantik dan SEO-friendly.
* **CSS3**: Menggunakan variabel kustom (CSS Variables) untuk manajemen tema dan Glassmorphism.
* **JavaScript**: Logika sederhana dan efisien untuk fitur *Theme Switcher*.
* **Tools**: Dioptimalkan dengan integrasi Python, Pyrogram, dan MongoDB untuk ekosistem bot-nya.

## 👤 Tentang Developer
Saya adalah seorang **Telegram Bot Developer** yang berfokus pada solusi otomatisasi dan monetisasi digital. Selain mengembangkan bot, saya juga menyediakan jasa penyediaan akun Telegram dan manajemen VPS.

## 📂 Struktur File
* `index.html`: Berisi struktur utama, konten profil, dan daftar proyek.
* `style.css`: Berisi seluruh konfigurasi visual, sistem grid, dan variabel warna mode gelap/terang.
