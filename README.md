# 🚀 WannnV Portfolio Website

Selamat datang di repositori resmi **WannnV**. Website ini adalah landing page portofolio yang dirancang dengan estetika **Premium Dark Mode**, fokus pada kecepatan, dan desain yang bersih untuk memamerkan layanan pengembangan bot Telegram.

## ✨ Fitur Utama
* **Modern UI/UX**: Desain minimalis menggunakan font *Space Grotesk* dan ikon dari *Font Awesome*.
* **Dual Theme Support**: Transisi halus antara mode gelap (dark) dan terang (light) melalui fitur *Theme Switcher*.
* **Responsive & Lightweight**: Kode yang efisien tanpa library berat, memastikan tampilan mobile-first yang optimal.
* **Interactive Elements**: Dilengkapi dengan animasi *fade-in*, efek *glassmorphism*, dan transisi hover pada kartu proyek.

## 🛠️ Tech Stack
* **HTML5**: Struktur web yang semantik dan rapi.
* **CSS3**: Menggunakan variabel kustom (CSS Variables) untuk manajemen tema dan styling modern.
* **JavaScript**: Logika *vanilla* JS yang sederhana untuk fungsionalitas pengalihan tema.
* **Ecosystem**: Dioptimalkan untuk integrasi Python (Pyrogram), Bash (Linux), dan MongoDB dalam pengembangan bot.

## 👤 Tentang Developer
Saya adalah seorang **Telegram Bot Developer** yang berfokus pada solusi otomatisasi dan monetisasi digital. Selain mengembangkan bot berkualitas, saya juga menyediakan jasa penyediaan akun Telegram, layanan VPS, serta integrasi Rest API & AI.

## 📂 Struktur File
* `index.html`: Berisi struktur utama, profil, store menu, dan daftar proyek aktif.
* `style.css`: Berisi seluruh konfigurasi visual, sistem grid, animasi, dan variabel warna.
